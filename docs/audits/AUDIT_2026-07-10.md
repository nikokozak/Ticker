# Ticker-Next Audit — verified synthesis

## Top findings (ranked)

1. **Editor exit can discard unsaved edits and leave document AI running [P1]** — lane: bridge + audit miss. **VERDICT: CONFIRMED.** Autosave waits 350 ms and its cleanup cancels the timer (`Web/src/components/StreamEditor.tsx:990-1022`); Back immediately unmounts the editor (`Web/src/App.tsx:250-253`), and unmount cleanup never calls `abortInFlightDocumentAI` (`StreamEditor.tsx:2334-2353`). Save rejection also only logs and leaves “Saving…” (`:1012-1018`). **Bites when:** navigating within 350 ms of editing, after a failed save, or during streaming AI. **Minimal fix:** centralize `saveNow`, make every editor-exit path await its terminal result, preserve an explicit dirty/error state, and cancel active AI during teardown. One save lifecycle fixes all three cases. **Effort:** M.

2. **Controlled CodeMirror causes full-document copies and extension reconfiguration on every edit [P1]** — lane: performance F1/F2. **VERDICT: CONFIRMED.** Every change converts the CM document to a string (`Web/node_modules/@uiw/react-codemirror/src/useCodeMirror.ts:61-85`), stores it in React state (`StreamEditor.tsx:512,2985-2987`), then the wrapper compares another `doc.toString()` (`useCodeMirror.ts:184-205`). Inline extension, setup, and callback identities cause `StateEffect.reconfigure` after that render (`StreamEditor.tsx:2901-2943`; `useCodeMirror.ts:161-182`). **Bites when:** typing or streaming AI into a large document. **Minimal fix:** keep live text in a ref/CM, update React state only for external reloads, and memoize the complete setup/extensions/callback surface. **Effort:** M.

3. **Selection-only transactions perform selection-, note-, and document-sized work [P1]** — lane: performance F5/F6/F7. **VERDICT: CONFIRMED.** Every drag tick copies and trims the full selection before and after debounce (`StreamEditor.tsx:1794-1834,1968-1988`). The dormant margin-note field creates/revalidates an array even without document changes, making its hidden plugin scan and clear DOM (`Web/src/extensions/MarginNotes.ts:153-170,301-329`). With Find open, selection changes rescan up to 999 matches (`EditorFindPanel.ts:165-178,223-230`). **Bites when:** dragging large selections—the reported symptom—especially with notes or Find open. **Minimal fix:** defer text extraction to the timer, return the unchanged note field on irrelevant transactions, omit the invisible view plugin, and cache Find matches by query/document. **Effort:** S.

4. **Provenance remapping rehashes every span and can merge different attribution [P2]** — lanes: performance F4/F8, bridge F9. **VERDICT: CONFIRMED.** `insertionChanges` is recomputed inside every-span mapping and `withHash` rereads covered text (`Web/src/extensions/ProvenanceField.ts:29-49,125-130`); autosave normalizes all spans again (`StreamEditor.tsx:345-347,999-1004`). Normalization merges adjacent spans using only `origin` and `requestId`, ignoring `sourceId` and `meta` (`ProvenanceField.ts:104-120`). **Bites when:** AI/capture-heavy documents are edited, or adjacent spans have different sources/apps. **Minimal fix:** compute changes once, retain hashes for spans whose covered text did not change, and merge only identical attribution—or stop merging. **Effort:** M.

5. **The bridge has no enforced concurrency or UI-thread boundary [P1]** — lanes: Swift F1/F3, bridge F1. **VERDICT: CONFIRMED.** Every inbound message is routed in an independent unstructured task (`Sources/Ticker/App/WebViewManager.swift:590-608`); `AIMessageHandler` mutates a plain task dictionary from route, cancellation, and child-task completion paths (`AIMessageHandler.swift:101,278-328`); `BridgeService.send` calls `WKWebView.evaluateJavaScript` without actor isolation (`BridgeService.swift:127-148`). Some producers manually hop to main, but the boundary itself does not enforce it. **Bites when:** cancel/start overlap, concurrent bridge requests, or UI sends race under load. **Minimal fix:** make `BridgeService.send` the single `@MainActor` send boundary and isolate the AI registry behind MainActor/a small actor, registering ownership before work starts. **Effort:** M.

6. **Migration proceeds after the required backup fails [P1]** — lane: Swift F6. **VERDICT: CONFIRMED.** Backup errors are caught and logged, then migration runs (`Sources/Ticker/Services/PersistenceService.swift:506-519`), contradicting the non-negotiable backup policy (`docs/DATA_MIGRATIONS.md:30-55`). **Bites when:** disk space or permissions fail during an upgrade, leaving no rollback copy. **Minimal fix:** require successful backup creation before migration; treat retention-rotation failure separately so an already-created backup is sufficient. **Effort:** S.

7. **Quick Panel cancellation does not identify callback ownership [P1]** — lane: Swift F2. **VERDICT: CONFIRMED.** Cancellation sets one shared flag, the next request immediately resets it, and old callbacks enqueue separate MainActor tasks that inspect only that shared flag (`Sources/Ticker/App/QuickPanel/QuickPanelManager.swift:538-630`). **Bites when:** request A is canceled and B starts before A’s queued chunk/completion/error drains; A can mutate B’s conversation or loading state. **Minimal fix:** capture an active request generation/UUID in every callback and ignore callbacks whose token is no longer current. **Effort:** S.

8. **Quick Panel AI append failure loses the answer and strands editor presence [P2]** — lanes: Swift F9, bridge F5. **VERDICT: CONFIRMED.** The editor is told AI started (`QuickPanelManager.swift:992-999`), but persistence append failure is only logged (`:1083-1108`); no terminal event reaches the editor, whose fallback lasts 130 seconds (`StreamEditor.tsx:1026-1043`). **Bites when:** SQLite is full, locked, or otherwise unwritable after the panel has closed. **Minimal fix:** return the append error and emit one correlated terminal failure event that clears presence and shows a sanitized toast. **Effort:** S.

9. **Stream-list loading reads and bridges the entire corpus [P2]** — lane: Swift F12. **VERDICT: CONFIRMED.** The summary query selects each complete document twice (`PersistenceService.swift:584-620`), and `StreamCodec` includes the entire text as `previewText` (`StreamCodec.swift:121-144`), although the list renders only bounded preview/count fields (`Web/src/App.tsx:400-456`). **Bites when:** opening a library with many or large documents. **Minimal fix:** delete `previewText` from the bridge, select a bounded prefix plus `length`, and delete exact word/image metrics unless their value justifies cached counters. **Effort:** S.

10. **Overlapping stream loads can display the stale response [P2]** — lane: bridge F3. **VERDICT: CONFIRMED.** `App` accepts every `streamLoaded` message (`Web/src/App.tsx:171-196`) while load/create/navigation requests carry no correlation (`:241-248,268-284`) and Swift routes them concurrently (`WebViewManager.swift:601-608`). The list disables after a normal click, but launch restore, search, Quick Panel creation, and rapid pre-render interactions still overlap. **Bites when:** an older load finishes after newer navigation. **Minimal fix:** attach a sequence/request ID and ignore stale responses. **Effort:** M.

11. **Callback requests lack a guaranteed terminal response [P2]** — lanes: Swift F4, bridge F6/F11. **VERDICT: CONFIRMED.** Invalid callback-bearing saves send only `bridgeError` (`StreamMessageHandler.swift:167-177`), the global persistence gate drops all messages—including auth—without responding (`WebViewManager.swift:601-606`), and `sendAsync` waits 30 seconds (`Web/src/types/bridge.ts:150-184`). Production hides generic `bridgeError` toasts (`Web/src/App.tsx:152-162`). **Bites when:** persistence initialization fails or a callback request fails validation. **Minimal fix:** extract `callbackId` before validation, always answer it with success/error, remove the global persistence gate, and show sanitized production errors. **Effort:** S.

12. **“Sources: All” can fall back to model knowledge after retrieval failure [P2]** — lane: Swift F14. **VERDICT: CONFIRMED, with corrected scope.** Retrieval exceptions are converted to no context (`Sources/Ticker/Services/AIOrchestrator.swift:67-88`). The response is not wholly silent: Swift emits mode `none` and the editor appends “From model knowledge” (`AIMessageHandler.swift:235-243`; `StreamEditor.tsx:1280-1295`). It still violates an explicit `all` scope by answering anyway. **Bites when:** retrieval storage fails during a source-required request. **Minimal fix:** fail `Sources: All`; for Auto, retain the visible model-knowledge label and add a retrieval-unavailable warning. **Effort:** S.

13. **Source indexing state can stick, and stale bookmarks are not refreshed [P2]** — lane: Swift F8/F10. **VERDICT: CONFIRMED.** Terminal ingest writes use `try?`; failure can leave durable status `indexing`, which is not re-enqueued (`Sources/Ticker/Services/IngestService.swift:40-49,171-181`). Stale bookmark resolution marks status but persists no refreshed bookmark (`SourceService.swift:48-76`). **Bites when:** transient SQLite failures occur or a bookmark resolves as stale repeatedly. **Minimal fix:** make terminal status persistence part of completion/requeue semantics, and persist a refreshed bookmark before returning the resolved URL. **Effort:** S.

14. **Device-key writes report success before durable persistence [P2]** — lane: Swift F7. **VERDICT: CONFIRMED.** `save` updates `cachedData` first and swallows both write attempts (`Sources/Ticker/Services/DeviceKeyService.swift:981-1017`); set/clear then transition auth state as if successful (`:468-518`). **Bites when:** disk or permissions prevent writing, causing session/restart disagreement or leaving a supposedly cleared key on disk. **Minimal fix:** make save throwing, update cache/state only after success, and let bridge callbacks report failure. **Effort:** M.

15. **The build graph retains MLX plus an obsolete standalone manifest [P2]** — lane: bloat F1/F2/F6. **VERDICT: CONFIRMED.** MLX is linked in `Package.swift:12-22` and `Ticker.xcodeproj/project.pbxproj:150,368-424,794-821`, but repository-wide Swift search found no MLX import. The standalone manifest omits actively imported Sparkle (`Sources/Ticker/App/AppDelegate.swift:5`) and is not used by `tickerctl`’s Xcode build path. Web source also directly imports six packages absent from `Web/package.json:13-20`. **Bites when:** resolving/building dependencies or changing transitive npm layout. **Minimal fix:** delete the unused standalone manifest, remove MLX from the Xcode graph, ignore generated lockfiles as already configured, and declare direct web dependencies. Re-add MLX only with the planned embedding implementation. **Effort:** S.

16. **Dead subsystems and small lifecycle leaks obscure the live architecture [P3]** — lanes: bloat, bridge, Swift. **VERDICT: CONFIRMED.** Vendor keys are compile-time disabled yet retain Keychain and bridge code (`SettingsService.swift:9-16,75-180`; `SettingsMessageHandler.swift:35-47`). Repository-wide searches found no Web sender for four Swift-only routes (`SourceMessageHandler.swift:38-50`; `StreamMessageHandler.swift:45-59`; `ProxyAuthHandler.swift:4-12`) and no caller for `Prompts.applyModifier`, `NoteIcon`, or `Colors`. Semantic search branches never produce non-text results (`SearchService.swift:46-112`). Several timers and post-delete asset cleanup are also untracked/swallowed. **Bites when:** maintainers trust dead contracts or carry unnecessary compiled surface. **Minimal fix:** delete zero-caller routes/types/services/UI artifacts, reduce search to its implemented text shape, clear component timers, and at least report orphaned-asset cleanup failure. **Effort:** M.

17. **Authoritative documentation mixes historical and current architecture [P3]** — lane: bloat F11/F12. **VERDICT: CONFIRMED.** The production plan’s opening audit still describes TipTap and a 2,498-line manager (`docs/PRODUCTION_READINESS_PLAN.md:5-39`) while the current file is 698 lines; the agent guide says roughly 450 and migrations v1–v13 (`CLAUDE.md:59-62`) although migrations reach v21. Proxy docs still claim client intent routing (`docs/PROXY_ARCHITECTURE.md:7-8,81-86`) while current orchestration explicitly has no classifier (`AIOrchestrator.swift:3-6`). **Bites when:** future work follows the wrong source of truth. **Minimal fix:** label completed audit phases historical and update only active architecture, migration, and proxy-routing statements. **Effort:** S.

## Rejected / demoted claims

- Performance F3, provenance X-ray as P1 → **P3**; its O(spans) rebuild is real, but the extension is off by default (`StreamEditor.tsx:509,2452-2463`).
- Performance F4, metadata work as P1 → **P2**; confirmed but proportional to accumulated spans/notes rather than universal.
- Performance F9, image widgets remeasure every rebuild → **rejected**; equal widgets are reused before `updateDOM` (`@codemirror/view/dist/index.js:2520-2541`).
- Performance F10, independent visible syntax passes as P2 → **P3**; bounded by `visibleRanges` and unsupported by profiling after the larger hot paths.
- Performance F11, broad widget DOM churn → **rejected as a finding**; the junior report itself establishes that the suspected bug is absent.
- Swift F4, callback hangs as P1 → **P2**; real, but reached on invalid payload or failed persistence initialization rather than normal requests.
- Swift F5, v16 catastrophic data loss → **P3/intentional cache invalidation**; a test explicitly requires legacy chunks be dropped and sources become pending (`StreamDocumentTests.swift:670-742`), while extracted text remains available for passthrough/reindex.
- Swift F7, device-key persistence as P1 → **P2**; correctness defect confirmed, but requires filesystem failure.
- Swift F11, full-document bridge saves as P2 → **P3 pending measurement**; saves are debounced and the canonical roadmap already says measure before adding a range protocol.
- Swift F13, orphaned assets as P2 → **P3**; limited to cleanup failure after an intentional stream deletion.
- Bridge F2, contract omissions as P1 → **P3**; the routes have no callers, and the checker does inspect Swift handlers but only contract→handler, not the reverse.
- Bridge F3, uncorrelated loads as P1 → **P2**; reachable, but normal list clicks are disabled once loading begins.
- Bridge F5, Quick Panel append failure as P1 → **P2**; severe result loss but dependent on persistence failure.
- Bridge F6, callbacks as P1 → **P2**; current Swift responders never emit an empty callback payload, leaving validation/global-gate failures as the real defect.
- Bridge F7, required payload defaults as P2 → **P3**; `sourceScope` and `verb` are contractually optional; only `streamId`, `imageURLs`, and image `requestId` validation actually drift.
- Bridge F8, non-finite append revisions → **rejected**; the current sender provides an `Int`, and JSON encoding cannot emit `NaN`.
- Bloat F1, MLX as P1 → **P2**; it harms build/dependency work, not shipped runtime behavior; the cited `Package.resolved` files are ignored generated files.
- Bloat F2, stale standalone manifest as P1 → **P2**; official builds use Xcode, making deletion a developer-hygiene fix.
- Bloat F3, disabled vendor Keychain as P1 → **P3**; confirmed dead surface with no active user path.
- Bloat F4, four dead handlers as P2 → **P3**; repository-wide search found no reachable sender.
- Bloat F5, semantic scaffolding as P2 → **P3**; confirmed speculative surface, but inert rather than incorrect.
- Bloat F6, undeclared web imports as P2 → **P3**; install fragility, not a current runtime failure.
- Bloat F10, dead modifier prompt as P2 → **P3**; zero references, deletion only.
- Bloat F11, production-plan drift as P2 → **P3**; misleading to maintainers but not runtime-affecting.
- Bloat F12, proxy/classifier doc drift as P2 → **P3**; same documentation-only impact.
